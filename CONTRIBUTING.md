# Contributing

Thank you for your interest in improving AI Data Science Team.

## Ways to Contribute

- Report bugs and usability issues
- Propose features and improvements
- Improve documentation and examples
- Submit code fixes and enhancements

## Before You Start

1. Search existing issues and pull requests to avoid duplicates.
2. Open an issue for non-trivial changes so the approach can be discussed.
3. Keep pull requests focused on one change set.

## Development Setup

1. Fork and clone the repository.
2. Create a virtual environment.
3. Install dependencies:

```bash
pip install -e ".[all]"
```

## Pull Request Process

1. Create a branch from `main`.
2. Make your changes with clear, minimal commits.
3. Run relevant tests and checks locally.
4. Update docs when behavior or public APIs change.
5. Open a pull request with:
   - Clear summary of what changed
   - Why the change is needed
   - Any important usage notes

## Coding Guidelines

- Follow existing code style and project structure.
- Prefer focused, minimal changes over large refactors.
- Avoid unrelated cleanup in the same pull request.
- Preserve backward compatibility where possible.

## Documentation

If you add or change agents/tools, update relevant docs:

- [docs/ADDING_AGENTS.md](docs/ADDING_AGENTS.md)
- [docs/ADDING_TOOLS.md](docs/ADDING_TOOLS.md)
- [docs/CONFIGURATION.md](docs/CONFIGURATION.md)

## Code of Conduct

By participating, you agree to be respectful and constructive in all project interactions.
